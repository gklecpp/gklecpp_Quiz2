# CS 5800 - QUIZ 2

## Test Driven Development with JUnit 5

This project demonstrates Test Driven Development (TDD) using Java, JUnit 5, and Maven.

## Programs

### Calculator
Implements basic arithmetic operations:
- Addition
- Subtraction
- Multiplication
- Division
- Even number checking

### DateChecker
Determins whether a month has 31 days using a Java enum.

## TDD Process
1. Red: Write a test that fails
2. Green: Write code to make the test pass.
3. Refactor: Improve the code while keeping tests passing

## Running Tests

Run the following command:

mvn test
